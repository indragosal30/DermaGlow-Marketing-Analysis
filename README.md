# DermaGlow A/B Testing Analysis

## Background
A/B Testing analysis untuk Meta Ads campaign brand skincare DermaGlow, 
membandingkan dua creative variant: Video_Review vs Static_Catalog.

## Tools
- Python (pandas, scipy) — Data Cleaning & Analysis
- Jupyter Notebook — Development Environment
- Power BI — Data Visualization

## Key Findings
- Static_Catalog menghasilkan 1.68x lebih banyak transaksi
- Static_Catalog menghasilkan 1.69x lebih besar revenue
- Perbedaan signifikan secara statistik (Chi-Square p-value: 0.0000)
- Static_Catalog terkuat di Sunscreen + Warm Audience (ROAS 3.0)

## Recommendation
Scale Static_Catalog sebagai main creative dengan alokasi 
70-80% budget, pertahankan Video_Review untuk top-of-funnel awareness.
